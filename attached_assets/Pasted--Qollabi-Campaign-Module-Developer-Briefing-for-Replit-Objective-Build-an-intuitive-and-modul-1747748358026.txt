📢 Qollabi Campaign Module — Developer Briefing for Replit
🎯 Objective
Build an intuitive and modular Campaign Builder in the Qollabi platform that enables partners (e.g. brokers) and providers (e.g. insurers) to create, manage, and share outbound sales campaigns. This includes:

Starting from templates or from scratch

Step-by-step campaign setup flow

AI-powered email generation

Smart follow-ups

Integrated delivery options

🧱 High-Level Architecture
🔹 Campaign Types
My Campaigns → Campaigns created by the logged-in user

Shared Campaigns → Campaigns shared by others (e.g. insurers)

New Campaigns → Start from template or from scratch

🪜 Campaign Creation Flow
When a user clicks "New Campaign", they follow this step-by-step builder:

1. Select List
Pull from smart views or entity-based lists already created in the platform (e.g. filtered opportunities or customers)

Lists can be uploaded or shared

2. Compose
Email editor with AI prompt support:

Text input or GPT-based prompts

Add dynamic content (e.g. Smart Updates, market insights)

Add logo (via file upload or partner profile)

Add formatting options:

Hyperlink

Form

Button

Use advanced settings to manage branding

3. Select Recipients
Recipients are contacts:

Linked to end-customers

Or linked to partners

Allow uploading new recipients manually if not already in the system

4. Follow-Up Messages (Optional)
Ability to schedule follow-up emails after a delay (X days/weeks)

Multiple follow-ups supported (at least 3 steps)

Each step can have:

New message body

Attachments

Different time delay

5. Settings
Define:

Timing (start time, scheduling)

Frequency (one-time, weekly, monthly)

Subject line

Sender identity

Option 1: Use connected user’s own email (OAuth integration)

Option 2: Send via Qollabi (username@qollabi.net)

6. Save / Send
Option to:

Save as draft

Send immediately

Preview before sending

🧩 Entity Integration
Each campaign must link to:

A List (origin of data)

One or more Recipients (contacts)

An optional Sponsor (e.g. insurer like AXA)

Possible link to Opportunities generated from the campaign

Logs of all campaign interactions (opens, clicks, responses)
