# Epic Story: Smart Customer Lists with AI-Powered Segmentation

## Epic Overview

**Title:** Smart Customer Lists - AI-Powered Customer Segmentation for Insurance Brokers

**Goal:** Transform the existing customer list interface into an intelligent segmentation tool that helps insurance brokers identify cross-sell, upsell, and retention opportunities using AI-powered suggestions and natural language queries.

**User Persona:** Insurance brokers and account managers who need to identify customer opportunities but lack technical expertise to create complex database queries.

---

## User Stories & Detailed UX/UI Specifications

### **Story 1: AI Suggestions Discovery - Primary Entry Point**

**As an** insurance broker**I want to** see AI-powered customer segment suggestions prominently when I open the customer list**So that** I can immediately identify high-value opportunities without manual analysis

#### UX/UI Details:

- **Visibility:** AI suggestions section appears by default when no smart list is active
- **Layout:** Full-width hero section positioned between header and customer controls
- **Visual Design:**

- Gradient background (blue-50 to indigo-50) for visual prominence
- Large "AI Smart List Suggestions" title with brain icon (w-6 h-6)
- "New" badge to highlight the feature
- Descriptive subtitle explaining the functionality



- **Card Grid:** Responsive 4-card layout (1→2→4 columns based on screen size)
- **Each Suggestion Card:**

- **Header:** Icon in colored background + Priority badge (High/Medium)
- **Content:** Bold title, 2-line description, metrics row
- **Footer:** "Preview Customers" button (outline style)
- **Interactions:** Hover effects (scale 105%, enhanced shadow, blue border)



- **Conversational CTA:** White box below cards with MessageSquare icon and "Create with AI Prompt" button


#### Technical Requirements:


### State Management:

```typescript
interface SmartListState {
  // Core data
  customers: Customer[]
  smartSuggestions: SmartSuggestion[]
  
  // UI state
  activeSmartList: string | null
  selectedCustomers: string[]
  showPromptBuilder: boolean
  isGenerating: boolean
  promptInput: string
  
  // Computed
  filteredCustomers: Customer[]
  currentStats: Stats
}
```

### Key Interactions:

1. **Default State:** Show AI suggestions, full customer list
2. **Preview State:** Hide suggestions, show banner, filter customers
3. **Prompt State:** Show builder, maintain current list state
4. **Clear Action:** Return to default state

## Testing Scenarios

### Critical User Flows:

1. **Discovery Flow:**

1. User lands → sees AI suggestions → clicks suggestion → previews customers → saves list



2. **Conversational Flow:**

1. User clicks "Create with AI Prompt" → enters description → generates → previews → saves



3. **Management Flow:**

1. User opens dropdown → sees saved lists → selects list → customers filter



4. **Campaign Flow:**

1. User previews segment → clicks "Launch Campaign" → campaign creation





### Edge Cases:

- No matching customers for prompt
- Network timeout during generation
- Mobile layout on small screens
- Empty saved lists state
