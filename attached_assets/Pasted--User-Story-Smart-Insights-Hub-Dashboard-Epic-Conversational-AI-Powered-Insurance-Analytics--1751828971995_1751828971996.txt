## User Story 1: Conversational AI Chat Interface

**As a** Insurance Broker**I want to** interact with an AI assistant through natural language conversations**So that** I can get instant insights about my portfolio and receive personalized recommendations

### Acceptance Criteria:

- Display chat interface with scrollable message history (max-height: 384px)
- Show AI messages with:

- Purple-themed styling (bg-purple-100, purple avatar)
- AI assistant branding with Lightbulb icon
- Structured message formatting with line breaks
- Bold text for emphasis on key metrics
- Inline action buttons within messages



- Show user messages with:

- Gray-themed styling (bg-slate-100)
- Clear visual distinction from AI messages
- Timestamp display



- Message features:

- Auto-scroll to latest message
- Message persistence during session
- Loading indicators for AI responses
- Error handling for failed messages



- Interactive elements:

- Clickable buttons within AI responses
- Copy message functionality
- Message reaction options





### Technical Requirements:

```typescript
interface ChatMessage {
  id: string;
  type: 'user' | 'ai';
  content: string;
  timestamp: string;
  actions?: MessageAction[];
  metadata?: {
    confidence: number;
    sources: string[];
    processingTime: number;
  };
}

interface MessageAction {
  id: string;
  label: string;
  type: 'button' | 'link';
  action: () => void;
  variant?: 'default' | 'outline' | 'destructive';
  icon?: React.ComponentType;
}

interface AIResponse {
  message: string;
  confidence: number;
  suggestedActions: MessageAction[];
  relatedInsights: string[];
}
```

### Component Structure:

```typescript
const ChatInterface: React.FC = () => {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [isLoading, setIsLoading] = useState(false);
  const messagesEndRef = useRef<HTMLDivElement>(null);

  const scrollToBottom = () => {
    messagesEndRef.current?.scrollIntoView({ behavior: "smooth" });
  };

  useEffect(() => {
    scrollToBottom();
  }, [messages]);

  return (
    <Card className="border-l-4 border-l-purple-500">
      <CardHeader>
        <CardTitle className="flex items-center gap-2">
          <MessageSquare className="h-5 w-5 text-purple-600" />
          AI Portfolio Assistant
        </CardTitle>
      </CardHeader>
      <CardContent>
        <div className="space-y-4 max-h-96 overflow-y-auto">
          {messages.map((message) => (
            <MessageBubble key={message.id} message={message} />
          ))}
          <div ref={messagesEndRef} />
        </div>
      </CardContent>
    </Card>
  );
};
```

```typescript
  trendDirection?: 'up' | 'down' | 'stable';
```

### Component Structure:

```typescript
const ProviderCard: React.FC<{ provider: ProviderPerformance }> = ({ provider }) => {
  const getInsightIcon = (type: string, trend?: string) => {
    switch(type) {
      case 'trend': return trend === 'up' ? '↗' : trend === 'down' ? '↘' : '→';
      case 'opportunity': return '⚡';
      case 'achievement': return '✓';
      default: return '→';
    }
  };

  return (
    <div className="text-center p-4 border rounded-lg">
      <div className={`text-2xl font-bold mb-2`} style={{ color: provider.brandColor }}>
        {provider.providerName}
      </div>
      <div className="text-sm text-slate-600 mb-3">{provider.description}</div>
      <div className="space-y-2">
        {provider.products.map((product) => (
          <div key={product.productName} className="flex justify-between text-sm">
            <span>{product.productName}</span>
            <span className="font-semibold">{product.clientCount.toLocaleString()} clients</span>
          </div>
        ))}
        {provider.insights.map((insight, index) => (
          <div key={index} className={`text-xs font-medium ${getInsightColor(insight.type)}`}>
            {getInsightIcon(insight.type, insight.trendDirection)} {insight.message}
          </div>
        ))}
      </div>
    </div>
  );
};
```

```typescript
interface NLQuery {
  id: string;
  query: string;
  intent: QueryIntent;
  entities: ExtractedEntity[];
  context: ConversationContext;
  timestamp: string;
}

interface QueryIntent {
  type: 'analysis' | 'comparison' | 'recommendation' | 'data_request';
  confidence: number;
  subtype?: string;
  parameters: Record<string, any>;
}

interface ExtractedEntity {
  type: 'product' | 'provider' | 'metric' | 'timeframe' | 'client_segment';

  confidence: number;
  position: [number, number];
}

interface ConversationContext {
  previousQueries: string[];
  currentFocus: string[];

  sessionData: Record<string, any>;
}

class NLQueryProcessor {

  extractIntent(query: string): QueryIntent;
  extractEntities(query: string): ExtractedEntity[];
  generateResponse(intent: QueryIntent, entities: ExtractedEntity[]): Promise<AIResponse>;
}
```
